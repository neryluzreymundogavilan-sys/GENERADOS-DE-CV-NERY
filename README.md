# Generador Web de Currículum (CV) — Dossier Documental

Aplicación web interactiva para la creación de Currículum Vitae en formato A4 y anexado de dossier documental (certificados en imagen y documentos Word `.docx`) con sistema de solicitudes desde dispositivos móviles y aprobación directa por la administradora.

## Flujo de Acceso
1. **Administradora:** Entra directamente a la página y al **Panel Admin** sin contraseña. Una vez que ingresa en su dispositivo, su navegador recuerda su acceso directo para entrar automáticamente sin pantallas de bloqueo.
2. **Estudiantes / Egresados (desde sus dispositivos):** Al abrir el enlace desde sus celulares o computadoras, completan sus datos en **Solicitar Ingreso** y envían su solicitud.
3. **Aprobación en Tiempo Real:** Todas las solicitudes enviadas desde distintos celulares se guardan y aparecen automáticamente en el **Panel Admin** para ser aceptadas, rechazadas o eliminadas.
